# Техническая документация проекта Quasaris Character Master

Данный нанейрослопленный документ содержит описание структуры и функциональности файлов кода и стилей проекта, расположенных в директории `ru.quasaris.characters.master`. Проект представляет собой приложение для управления листами персонажей.

---

## 1. Основные компоненты (`ru.quasaris.characters.master`)

### MainActivity.kt
Точка входа в приложение. Содержит настройку навигации (`NavHost`) и управление основным состоянием списка персонажей. Реализует переходы между главным меню (`MenuWindow`), промежуточным экраном создания (`empty_window`) и редактором персонажа (`CreateWindow`).

### Models.kt
Описывает структуру данных проекта:
*   `Character`: Основной класс персонажа. Содержит характеристики, навыки, хиты, выбранные состояния (`selectedConditions`), уровень истощения (`exhaustion`), а также списки формул для КД, инициативы, скорости и щита.
*   `ArmorClassEntry`, `InitiativeEntry`, `SpeedEntry`, `ShieldEntry`: Модели для хранения различных вариантов расчета боевых параметров.
*   `FormulaEntry`: Интерфейс для объектов, содержащих формулы.

### CharacterRepository.kt
Отвечает за локальное хранение данных. Использует `SharedPreferences` и библиотеку `Gson` для сериализации/десериализации списка персонажей в JSON-строку.

### MenuWindow.kt
Экран главного меню.
*   Отображает список персонажей в виде карточек (`CharacterCard`).
*   Реализует функционал импорта персонажа из JSON-файла.
*   Позволяет выбирать нескольких персонажей для массового удаления.
*   Содержит кнопку создания нового персонажа, ведущую на экран-заглушку.

### CharacterDetailWindow.kt
Вспомогательный компонент для детального отображения информации о персонаже (на данный момент находится в процессе интеграции или используется для альтернативных представлений).

## 2. Секции главного окна редактора (`ru.quasaris.characters.master.MainWindow`)

Директория содержит компоненты, составляющие основное рабочее пространство редактора персонажа.

### CreateWindow.kt
Центральный компонент редактирования. Собирает воедино все секции (личность, атрибуты, хиты, условия, формулы) и управляет общим состоянием редактируемого объекта `Character`. Поддерживает переключение между режимами создания нового и редактирования существующего персонажа.

### CharacterDataHandler.kt
Вынесенная логика для обработки данных персонажа: создание объекта, экспорт в формат JSON и вспомогательные функции трансформации данных.

### AttributesSection.kt
Отвечает за отображение и редактирование основных характеристик (Сила, Ловкость и т.д.). Содержит `StatCard` для каждой характеристики и блок для пассивных проверок.

### HitPointSection.kt
Секция управления здоровьем. Включает `HealthDialog` для удобного внесения урона или лечения, а также управление временными хитами.

### CharacterIdentitySection.kt
Верхняя часть редактора. Управляет аватаром персонажа, его именем, классом и основными кнопками управления профилем. Служит оберткой над `CharacterHeader`.

### ConditionsSection.kt
Логика управления состояниями персонажа. Загружает список возможных состояний из внешнего файла `Conditions.md` и позволяет переключать их для текущего персонажа.

### CombatCalculationsSection.kt
Специализированный объект для расчета боевых параметров: Класса Доспеха (КД), Инициативы и Скорости на основе формул и характеристик персонажа.

## 3. Компоненты заголовка и расчеты (`ru.quasaris.characters.master.HeaderCode`)

Директория содержит детализированные UI-компоненты "шапки" листа персонажа и логику вычислений.

### CharacterHeader.kt
Основной визуальный компонент заголовка. Объединяет информацию об имени, уровне (с прогресс-баром опыта) и быстрые индикаторы параметров: КД (с подсветкой активного щита), Инициатива, ХП и Состояния (с индикацией количества активных эффектов и уровня истощения).

### StatCalculations.kt
"Математическое ядро" проекта. Содержит формулы расчета модификаторов, парсинг условий из Markdown и обработку выражений в формулах (поддержка команд `MAX`, `MIN`, `CEIL`, `FLOOR`, а также подстановок характеристик в формате `[СИЛ]`).

### HitPointPanel.kt
Специализированная панель для отображения текущего состояния здоровья, отображающая хиты, временные хиты и визуальные индикаторы.

### LevelPanel.kt
Компонент для отображения уровня, прогресса опыта и бонуса мастерства персонажа.

### FormulaPanels.kt
Универсальные интерактивные панели (`FormulaPanel`) для отображения и редактирования КД, Инициативы, Скорости и Щита. Поддерживают несколько пресетов, кастомные формулы и выбор активного пресета.

### ConditionsPanel.kt
UI-элемент для отображения активных состояний персонажа с форматированным описанием их эффектов. Включает секцию управления уровнем Истощения (`ExhaustionSection`) с автоматическим расчетом штрафов к проверкам и скорости.

### CommonHeaderWidgets.kt
Библиотека вспомогательных UI-виджетов: иконки характеристик (`StatIconBox`) с поддержкой тактильной отдачи, отрисовка фигур (`SquirclePath`) и другие элементы оформления.

## 4. Дизайн и темы (`ru.quasaris.characters.master.ui.theme`)

### Theme.kt
Настройка Material 3 темы приложения. Поддерживает динамические цвета (Material You) для Android 12+ и автоматическое переключение между темной и светлой темами.

### Color.kt
Определение цветовой палитры проекта для темной и светлой тем.

### Type.kt
Настройки типографики: определение шрифтов, размеров и стилей текста, используемых в приложении.
